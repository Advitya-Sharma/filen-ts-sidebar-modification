# Office test corpus

Real-world word-processing, spreadsheet and ODF files for the opt-in corpus tests. The files are not in the repository: `pnpm run corpus:fetch` downloads them from their original sources into `.corpus/` and verifies each against its SHA-256 here. Every file is an unmodified download; none was authored or re-saved for the corpus.

- `manifest.json`: per file the path, size, SHA-256, source, licence and download URL (raw files at pinned commits, GOV.UK asset URLs).
- `catalogue.json`: per file the producer, app.xml metadata, fonts, pagination signals and feature counts (zero and empty values omitted), to pick files by feature.

Generated by `pnpm run corpus:manifest`; do not edit.
